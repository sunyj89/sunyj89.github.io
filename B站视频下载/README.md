# B站视频下载

本目录用于统一归档指定的 B 站视频及其来源说明，与仓库中已有的“抖音视频下载”目录分开维护。

## 目录约定

- 每个视频使用独立目录：`B站视频下载/<BV号>-<简短标题>/`。
- 单个视频保存完整音视频 MP4；多分 P 视频使用 `p01.mp4`、`p02.mp4` 等名称。
- 每条视频的说明记录原始链接、标题、分 P、下载日期、实际分辨率、文件大小及下载入口。
- 清晰度以实际文件核验结果为准，未完成或未上传的文件不登记为归档成功。

## 文件存放

- 适合普通 Git 的小文件可直接存入本目录。
- 较大的视频优先使用本仓库 Releases 保存附件，并在对应视频目录保留下载链接；实际上传前检查当时的文件大小限制。
- 不改变现有主页或“抖音视频下载”目录，不保存登录信息、Cookie、认证文件或下载临时缓存。

参考：[GitHub 大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。

## 归档记录

当前仅建立归档目录，尚无 B 站视频文件。收到具体链接或 BV 号并完成下载、上传核验后，再添加视频记录。

本仓库为公开仓库，归档的文件和说明可被公开访问。
